# Контракты DEXonEVER

Исходники контрактов биржи DEXonEVER (Everscale) и моста Everscale ↔ BSC.

```
contracts/
├── exchange/            биржа, Everscale (T-Sol)
│   ├── libraries/       константы, газ, ошибки, математика пар и маршрутов
│   ├── structures/      общие структуры и события
│   └── tip3/            токен TIP-3: токены фабрики и LP-токены пар
└── bridge/
    ├── everscale/       мост, сторона Everscale (T-Sol)
    └── evm/             мост, сторона BSC (Solidity)
```

## Биржа — `exchange/`

| Контракт | Назначение |
|---|---|
| `DexRoot` | Корень биржи: владелец и роли, коды контрактов и их обновление, списки токенов и пар, развёртывание пар и хранилищ |
| `DexPlatform` | Платформа: даёт дочерним контрактам постоянный адрес, не зависящий от их кода |
| `DexPair` | Пара (обычная и stable): обмен, вклад и вывод ликвидности |
| `DexPairGovernance` | Управление парой со стороны корня: пауза, заморозка, комиссия, коэффициент A stable-пары |
| `DexPairLpToken` | LP-токен пары: корень TIP-3, LP-кошелёк пары, выпуск и сжигание LP |
| `LpAccount` | Счёт вкладчика для двустороннего вклада: собирает обе половины и передаёт их паре |
| `DexTokenVault` | Хранилище токена TIP-3: приём токенов для операций и выплаты |
| `DexNativeVault` | Хранилище нативного EVER |
| `VaultJournal` | Журнал операций хранилища: операция ждёт подтверждения пары, при отскоке средства возвращаются |
| `TokenFactory` | Фабрика токенов TIP-3 |
| `TokenList` | Список токенов или пар: белый, чёрный, зарезервированный |
| `Launchpad` | Запуск токенов: создаёт кривые |
| `LaunchCurve` | Кривая запуска одного токена: покупка и продажа до порога, затем пул на бирже |
| `DexRegistry` | Шард реестра развёрнутых хранилищ и пар |
| `DexHub` | Узел событий: контракты одной группы сообщают ему о своих событиях |
| `EventBell` | Сигнал узлу событий из каждой транзакции с событием |
| `EverSurplus` | Вывод владельцем ничьих средств: с объявлением, причиной и выдержкой |

## Мост — `bridge/`

**Everscale** (`bridge/everscale/`):

| Контракт | Назначение |
|---|---|
| `BridgeRoot` | Корень моста: токены, раунды релеев, выпуск при депозите и сжигание при выводе |
| `DepositEvent` | Депозит из BSC: голоса релеев, выпуск токенов после порога |
| `WithdrawalEvent` | Вывод в BSC: подписи релеев EIP-712 для `BridgeVault.withdraw` |
| `BridgeStructs`, `libraries/` | Структуры, константы, ошибки, газ |

**BSC** (`bridge/evm/`):

| Контракт | Назначение |
|---|---|
| `BridgeVault` | Хранилище токенов: депозиты, выводы по подписям релеев, лимиты, очередь крупных выводов, пауза |
| `VaultProxy` | Прокси ERC-1967: постоянный адрес хранилища, код обновляется через UUPS |
| `BridgeConstants` | Константы хранилища |
